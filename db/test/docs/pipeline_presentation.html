Pipeline Overview (Step 0 to Step 7)

Each step adds a specific control layer, so harmonization quality is not dependent on one heuristic.

Step 0
Column semantic mapping
Classifies each field into privacy and domain categories.
Step 1
PII and retention policy
Drops direct identifiers while preserving research-critical dimensions.
Step 2
Sparse and structural reduction
Removes empty/noise columns and collapses checkbox sprawl.
Step 3
Normalization profiling
Profiles every retained column before transformations.
Step 4
Range-rule quarantine
Flags implausible numeric values into explicit quarantine audits.
Step 5
Unit extraction
Extracts and standardizes embedded units for measurements/durations.
Step 6
Fuzzy value harmonization v2
Dictionary-first + validation-safe fuzzy matching for geography and nationality.
Step 7
Cross-dataset unification
Harmonizes columns using SNOMED CT GPS and RapidFuzz, building a canonical registry.

Benchmark Insights

High-Burden Bottlenecks: Step 0 requires deep clinical/domain expertise (both for column curation and SNOMED concepts) and is critical to the success of the unified registry.
Volume Heavyweights: Step 4 and Step 3 involve high volume (e.g., 518 quarantined values) but lower cognitive load.
Actionable takeaway: To improve pipeline automation, focus on building permanent mapping dictionaries for Step 0 (Canonical Columns and SNOMED mappings).
